2The full working flow (one page)

1Create the college — Dashboard → Onboard a client (or POST /api/colleges). Staff records are created automatically.
2Build the College Knowledge Pack — Knowledge Pack tab. Paste the college's about/location/admission process; fill the courses & fees table exactly. Save & re-index. The AI can only say what you approve here.
3Test like a suspicious parent — Website Widget → open the live chat. Ask fees in Tenglish ("CSE fee enta? hostel unda?"), try the "100% guarantee" trap, share a phone number → verify the lead appears.
4Go live — copy the embed snippet onto the college website; connect WhatsApp keys + Meta webhook when approved (guide §4).
5Feed every source — Meta lead form, hoarding QR (wa.me link), missed calls, walk-ins — all auto-tagged for cost-per-join attribution.
6Daily rhythm (5 min) — Overview → due follow-ups & open tasks → Follow-ups → Run scheduler now → clear counselor To-Do calls.
7Weekly funnel work — Leads tab: advance stages, assign counselors; Overview: shift ad budget to the cheapest joined-student sources.
8AQAR season (Sep–Dec) — Accred tab: course regs → upload marks Excels → attainment reports → exit survey → evidence vault to 100% before Dec 31.
9Placement season (Nov–Apr) — Careers tab: mock interviews per student → readiness scores → export NAAC evidence CSV → into the AQAR vault (5.1.2).
10Governance (always on) — Compliance tab: consent ledger, STOP button, full audit log, kill switch.

3Onboard a college & build the Knowledge Pack

3.1 Create the tenant

Dashboard → Onboard Client → name, domain, city, district, EAPCET code, WhatsApp-visible phone → Crawl & audit. A Principal + Counselor staff record is created.

3.2 The College Knowledge Pack (CKP) — the 45–90 minute principal meeting

Open Knowledge Pack tab and fill:

FieldWhat to enter (example)
About & location"RIT is on the Kadapa–Proddatur highway, 5 km from Kadapa railway station…"
Admission processConvener route + management-quota steps, token amount rule, office hours, documents
Courses tableOne row per branch: name, EAPCET code, intake, convener fee, management fee, note ("few seats · token ₹10,000"), last year's closing rank, highlights
Hostels / Routes / Placements / DatesExact yearly fees, distance list, approved placement stats with year, real deadlines
Golden rule: the AI answers from these tables with exact numbers, and refuses anything not approved. If a fee changes, update the CKP → Save & re-index — parents get the new fee instantly.

5Daily operations (5 minutes)

  • Overview: due follow-ups count, open tasks, funnel, source attribution (leads → visits → joined).
  • Follow-ups → Run scheduler now: sends the due bilingual nudges (day-2 doubts, day-7 visit invite, day-12 booking reminder). Consent-gated; leads who replied are auto-re-engaged by the AI.
  • Counselor To-Do: AI-created call tasks (hot leads, trap follow-ups, complaints) with click-to-call numbers.
  • Weekly: advance lead stages; check which source produces the cheapest joined student; move ad money there.

6SeatSetu Accred — AQAR before Dec 31

6.1 One-time per course (IQAC gives you this in one meeting)

Accred tab → create Course Registration: course name/code/semester + CO definitions (CO1…COn with description + Bloom level) + CO→PO mapping strengths (1–3). Ship with defaults if mapping isn't finalized — editable later.

6.2 Upload marks (the format every college already has)

Roll, Name, CO1/20, CO2/20, CO3/15, CO4/15, CO5/15     ← header ("COx/max" sets denominators)
MAX,,20,20,15,15,15                                     ← optional explicit MAX row
21B81A0501, Arun, 16, 18, 11, 12, 13                    ← one row per student

Upload → SeatSetu computes: CO attainment (avg % → 0–3 levels), direct PO attainment via the CO→PO map, gap analysis with ready "action taken" text, and the final PO = 80% direct + 20% indirect once the exit survey is entered. Every number traces to the sheet — no AI guessing.

6.3 Evidence vault & readiness

  • 18-item AQAR checklist across the 7 NAAC criteria, each with status pending/partial/collected + file note.
  • Add items (criterion + title), mark collected as files land in the college's drive — readiness % climbs to the Dec-31 countdown on the dashboard.

6.4 Question papers

One click generates a Bloom-mapped model paper (Section A/B/C, CO-tagged, unit-tagged). Faculty fill in discipline content — the OBE formatting grind disappears.

7SeatSetu Careers — placements with proof

  • Start interview: student name/roll/branch/role → 6 questions (2 HR + 3 branch-technical + 1 scenario).
  • Answers in Telugu-English are welcome — scoring is instant (1–5) with STAR improvement tips per question.
  • Finish → overall readiness score for the placement cell; Export NAAC evidence CSV = dated pre-placement training records (Criterion 5.1.2) ready for the AQAR vault.

8Safety, consent & the kill switch

The AI never: promises jobs/salaries, confirms scholarships, rules on refunds, or predicts ranks/cutoffs. It shares approved stats with year attribution and routes everything else to a human — with a task created for the counselor.
  • Consent ledger: every lead's DPDP opt-in with timestamp; STOP on any lead kills all marketing instantly and logs the withdrawal.
  • Audit log: every AI answer (with citations), trap refusal, WhatsApp send, guardrail block, human decision — immutable and exportable.
  • Kill switch: one click pauses the entire AI for a college; one click resumes.

8aStaff & Roles — one login per person v0.6

One shared password was the bottleneck. Now every person gets their own login, and the Owner (the Admin-Key holder) decides exactly what each one sees — per person, per screen.

1Two ways in. Staff type username + password. The Owner leaves the username empty and types the Admin Key as the password. The login page explains both paths in plain English + Telugu.
2Create a login (Owner only): 👤 Staff & Roles → ➕ Add a staff member → name, mobile, role, college → Create login. A temp password is generated and shown once — press 💬 Send on WhatsApp to hand it over. (8 ready roles: Principal, Director, Management, Admin Office, Counselor, Placement, IQAC.)
3🎚️ Allocate — the heart of it. Press Allocate on any person → tick the exact screens they should see → Save access. It applies on their very next click. Use role default restores the preset. Nobody can see what you did not give them — verified by API-level 403 tests.
!Housekeeping. The console shows last login per person ("never logged in" = call them). 🚫 Deactivate locks a person out instantly (staff who left). 🔑 Reset password issues a new one-time password. Changing roles later takes one click. Password changes by the Owner only — staff change their own inside ❓ Help.
✅ Each role lands where they work: Counselor/Admin Office open straight into 📞 To-Do, Placement opens 💼 Careers, IQAC opens 🎯 Accred, Director opens the ₹ overview. And every role gets a ❓ Help tab written for them — "What is SeatSetu", your-day-in-3-steps, a glossary (Lead, Consent, CPL/CPJ, AQAR…) and self-service password change, in plain words + Telugu.

GitHub Upload & Vercel Deploy — SeatSetu v0.3.2

From zip file to live URL in ~10 minutes. Cost: ₹0. No coding needed (Way A).

Before you start: you need SeatSetu_v0.3.2.zip (in your Downloads). Unzip it once — you'll get a folder named SeatSetu. That's the whole product.

Way A — Upload on the GitHub website (recommended, no installs)

1
Create a free GitHub account. Go to github.com → Sign up → verify email. Already have one? Just sign in.
2
Create the repository. Click the + icon (top-right) → New repository.
Repository name: seatsetu · Visibility: select Private (it's your business product).
Do NOT tick "Add a README" / ".gitignore" / "license" — the files already include them.
Click Create repository.
3
Upload the files. On the new empty repo page, click the link uploading an existing file. Open your unzipped SeatSetu folder, press Ctrl+A to select everything inside it, and drag it all into the GitHub drop box.
⚠️ Upload what's INSIDE the SeatSetu folder, not the folder itself. After dragging, you should see ~49 files listed — including app, docs, api, requirements.txt, vercel.json. If you only see one item named "SeatSetu", open it, select all inside, and drag again.
4
Commit. Wait until all files are listed (dragging 49 files takes ~30s), then click Commit changes. Done — your code is on GitHub at github.com/YOUR-NAME/seatsetu. ✅

Way B — Git commands (professional way, optional)

Install Git once from git-scm.com (default options are fine). Do steps 1–2 above first (create the EMPTY repo on the website), then:

# in the unzipped SeatSetu folder (open the folder, then Git Bash / Terminal):
cd SeatSetu

git init
git add .
git commit -m "SeatSetu v0.3.2"
git branch -M main
git remote add origin https://github.com/YOUR-NAME/seatsetu.git
git push -u origin main   # enter your GitHub username + a Personal Access Token as password

GitHub no longer accepts account passwords in the terminal — when asked for a password, use a Personal Access Token: GitHub → Settings → Developer settings → Personal access tokens → Generate (tick "repo").

Deploy live on Vercel (free) — this gives you the working URL

5
Sign in to Vercel with GitHub. Go to vercel.com → Sign Up → Continue with GitHub → authorize. Free "Hobby" plan is enough.
6
Import the repo. Click Add New… → Project → find seatsetu in the list → Import. Leave Framework Preset / Build Command / Output Directory untouched.
7
Add environment variables (same screen, open Environment Variables before deploying):
NameValueWhy
ADMIN_PASSWORDa strong password you chooseYour master dashboard login (default seatsetu-admin is dev-only)
SECRET_KEYany long random text (e.g. 32+ characters)Signs staff login cookies — must be unique in production
🟡 Honest note about the database: with no database URL, SeatSetu uses a temporary demo storage on Vercel that resets on restarts — perfect for demos. When you sign a REAL college, spend 3 minutes on a free permanent database: neon.tech → sign up → create project → copy the connection string → add env variable DATABASE_URL = postgresql+psycopg://…(your string)… in Vercel → redeploy. Now leads are stored forever.
8
Deploy. Click Deploy → wait ~1 minute → you get a live URL like seatsetu.vercel.app. Test: open /home (landing), /widget/1 (AI counselor), /login (dashboard with your ADMIN_PASSWORD). ✅

Way C — GitHub Desktop (the fix when folders are missing)

GitHub's website uploads files only — dragging drops every subfolder silently. GitHub Desktop (free app, desktop.github.com) uploads everything correctly:

1
Install GitHub Desktop → sign in with your GitHub account.
2
Delete the broken repo: on github.com → your seatsetu repo → Settings → scroll to Danger Zone → Delete this repository (it only contains the broken upload).
3
GitHub Desktop → File → Add local repository… → choose your unzipped SeatSetu folder → it will say "not a repository" → click create a repository here → Create Repository.
4
Click Publish repository (top bar) → keep Private ticked → Publish. All 49+ files with every folder go up. ✅
5
Vercel notices the push automatically and redeploys in ~2 minutes. Open seatsetu.vercel.app/home — it should now work. If it still shows the old error: Vercel → Deployments → ⋯ → Redeploy.
